# IceStream Lakehouse

This folder contains the lakehouse configuration and local data storage used by IceStream.

## Current Implementation

The current lakehouse layer stores validated transactions in JSON Lines format.

### Data Flow

Kafka → Flink → Data Quality Validation → Lakehouse

Only transactions with the status `VALID` are written to the lakehouse.

### Files

- `config.py` - Loads the lakehouse storage path.
- `config.env` - Stores the local lakehouse path.
- `writer.py` - Writes valid transactions to the lakehouse.
- `data/transactions.jsonl` - Local transaction data generated by the pipeline.

### Validation Behavior

- `VALID` → Transaction is stored.
- `BAD_DATA` → Transaction is rejected.
- `SCHEMA_DRIFT` → Transaction is rejected.

## Future Work

The local JSONL storage will later be extended toward an Apache Iceberg-based lakehouse when a compatible Flink and Iceberg runtime is available.
